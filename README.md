# Rock-Paper-Scissors Game 

A classic Rock-Paper-Scissors game with polished UI including buttons to make choices and play the game against computer.

Score updates after every round, First to score 5 wins the game.

It shows result after every round and declare winner whoever score 5 first.

I used JavaScript EventListeners to make the buttons functional.

Practiced Dom manipulation to change the images and results on the web page.

Learned about various dom methods and events concept in javascript while building this project.
